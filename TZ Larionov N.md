2. Вывести **общую сумму оплаченных заказов** по каждому пользователю (включая пользователей без заказов).
```
select
    users.name,
    coalesce(sum(orders.total), 0)
from users
left join orders
    on users.id = orders.user_id
    and orders.status = 'completed'
group by users.id, users.name;
```

3. Вывести пользователей, у которых **есть хотя бы один заказ со статусом `returned`**.
```
select distinct
    users.name
from users
inner join orders
    on users.id = orders.user_id
where orders.status = 'returned';
```

4. Вывести **топ-3 пользователей по сумме оплаченных заказов**.
```
select
    users.name,
    sum(orders.total) as orders_sum
from users
inner join orders
    on users.id = orders.user_id
where orders.status = 'completed'
group by users.id, users.name
order by orders_sum desc, users.id
limit 3;
```
